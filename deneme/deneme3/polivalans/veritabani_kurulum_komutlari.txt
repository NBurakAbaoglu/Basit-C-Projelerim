POLİVALANS PROJESİ VERİTABANI KURULUM KOMUTLARI
=====================================================

Bu dosya, Polivalans projesinin veritabanını başka bir bilgisayarda kurmak için gerekli komutları içerir.

GEREKSİNİMLER:
- XAMPP (Apache + MySQL + PHP)
- MySQL/MariaDB veritabanı sunucusu
- PHP 7.4 veya üzeri

KURULUM ADIMLARI:
================

1. XAMPP KURULUMU:
   - XAMPP'ı resmi web sitesinden indirin: https://www.apachefriends.org/
   - Kurulumu tamamlayın
   - XAMPP Control Panel'i açın
   - Apache ve MySQL servislerini başlatın

2. VERİTABANI OLUŞTURMA:
   MySQL komut satırından veya phpMyAdmin'den aşağıdaki komutları çalıştırın:

   mysql -u root -p
   
   CREATE DATABASE kurumsal CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   USE kurumsal;

3. VERİTABANI YAPISINI İÇE AKTARMA:
   SQL dosyasını içe aktarmak için aşağıdaki komutlardan birini kullanın:

   A) Komut satırından:
   mysql -u root -p kurumsal < "kurumsal (1).sql"
   
   B) phpMyAdmin'den:
   - phpMyAdmin'i açın (http://localhost/phpmyadmin)
   - "kurumsal" veritabanını seçin
   - "İçe Aktar" (Import) sekmesine tıklayın
   - "kurumsal (1).sql" dosyasını seçin ve içe aktarın

   C) SQL Sorgusunu Direkt Çalıştırma:
   Aşağıdaki SQL kodunu MySQL komut satırında veya phpMyAdmin'de çalıştırın:

-- Yordamlar
CREATE DEFINER=`root`@`localhost` PROCEDURE `GetOrganizationSkills` (IN `org_id` INT)   BEGIN
    SELECT 
        os.id,
        os.skill_name,
        os.skill_description,
        COUNT(ps.id) AS planned_count,
        COUNT(e.id) AS events_count
    FROM organization_skills os
    LEFT JOIN planned_skills ps ON os.id = ps.skill_id
    LEFT JOIN events e ON os.id = e.lesson_id
    WHERE os.organization_id = org_id
    GROUP BY os.id, os.skill_name, os.skill_description
    ORDER BY os.skill_name;
END$$

CREATE DEFINER=`root`@`localhost` PROCEDURE `GetPersonDetails` (IN `person_name` VARCHAR(255))   BEGIN
    SELECT 
        p.id,
        p.name,
        p.company_name,
        p.title,
        p.registration_no,
        COUNT(ps.id) AS planned_skills_count,
        GROUP_CONCAT(DISTINCT o.name ORDER BY o.name SEPARATOR ', ') AS organizations
    FROM persons p
    LEFT JOIN planned_skills ps ON p.id = ps.person_id
    LEFT JOIN organizations o ON ps.organization_id = o.id
    WHERE p.name = person_name
    GROUP BY p.id, p.name, p.company_name, p.title, p.registration_no;
END$$
DELIMITER ;

-- Tetikleyiciler
DELIMITER $$
CREATE TRIGGER `tr_update_enrolled_count` BEFORE UPDATE ON `events` FOR EACH ROW BEGIN
    IF NEW.capacity < 0 THEN
        SET NEW.capacity = 0;
    END IF;
    
    IF NEW.enrolled_count < 0 THEN
        SET NEW.enrolled_count = 0;
    END IF;
    
    IF NEW.enrolled_count > NEW.capacity THEN
        SET NEW.enrolled_count = NEW.capacity;
    END IF;
END$$
DELIMITER ;

SORUN GİDERME:
==============

1. Bağlantı hatası alıyorsanız:
   - MySQL servisinin çalıştığından emin olun
   - config.php'deki veritabanı bilgilerini kontrol edin
   - MySQL şifresini doğru girdiğinizden emin olun

2. Karakter kodlama sorunları:
   - Veritabanının utf8mb4 karakter seti kullandığından emin olun
   - MySQL bağlantısında charset=utf8mb4 ayarını kontrol edin

3. Dosya yolu sorunları:
   - Proje dosyalarının doğru konumda olduğundan emin olun
   - XAMPP'ın htdocs klasörüne kopyalandığından emin olun

4. İzin sorunları:
   - Windows'ta yönetici olarak çalıştırın
   - Linux/Mac'te uygun dosya izinlerini ayarlayın
